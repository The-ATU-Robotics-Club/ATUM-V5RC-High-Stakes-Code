Detailed Description

This class encapsulates the logic behind the Sparkfun Optical Tracking Odometry Sensor (OTOS). It mostly acts as a wrapper around the SerialDevice class, with it's own set of commands and responses.

The OTOS should be set to receive data relative to the robot, not the field.
